About QuickNotes

QuickNotes is a simple note-taking app for jotting down ideas, reminders and to-dos before they slip away. It is built for speed, so you can write a note, find it again and get back to what you were doing.

How to use QuickNotes

  1. Open QuickNotes and click the "New note" button.
  2. Type a title and write your note in the text area.
  3. Save the note so it appears in your list.
  4. Click any saved note to read, edit or delete it.

Features

  • Create notes instantly
  • Edit and delete notes at any time
  • Clean, distraction-free layout
  • Keyboard shortcuts for common actions

Keyboard shortcuts

Shortcut Action
Ctrl + N Create a new note
Ctrl + S Save the current note
Ctrl + D Delete the current note
